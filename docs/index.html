WINDOWS SMARTSCREEN NOTE

First-time installation help

Because Istiqamah is a brand new, free, independent application, Windows may display a blue dialog stating "Windows protected your PC". This is normal Microsoft behavior for new software that has not yet accumulated thousands of downloads.

1
Click "More info"

On the blue SmartScreen window, click the small underline link labeled More info.

2
Click "Run anyway"

A second button will appear at the bottom right. Click Run anyway to begin setup.

3
Enjoy Istiqamah

The installer completes in seconds. The prompt only appears once during initial installation.

QUESTIONS & ANSWERS

Frequently Asked Questions

Everything you need to know about the app, storage, and features.

Is Istiqamah really free?

Yes, completely free. There are no advertisements, paid tiers, subscriptions, or hidden charges. The application was built to be a simple, sincere tool for daily personal consistency.

Where is my data stored?

Your checklist and history are stored on your own computer.

Does it work on Mac, Linux, or mobile?

Istiqamah is currently optimized specifically for Windows 10 and 11 desktop and laptop computers. A native macOS build is planned for a future release.

How do the Friends leaderboard and Hikmah Quiz work?

Each user gets a private 8-character Friend Code (e.g. IST-WPU4). Sharing your code lets friends compare daily progress percentages, streaks, and scores from the daily 5-question Hikmah Quiz on a clean leaderboard.

How do I uninstall the app if I ever need to?

Istiqamah follows standard Windows installation standards. You can uninstall it anytime by heading to Windows Settings > Apps > Installed Apps, searching for Istiqamah, and clicking Uninstall. It removes cleanly with no persistent background processes.
